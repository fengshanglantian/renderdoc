# Private-build packaging

Tooling for packaging this private fork's patched RenderDoc binaries into
a self-contained, redistributable directory + zip that mirrors the official
MSI install layout.  Intended for internal distribution only — the official
RenderDoc release process lives elsewhere.

## Files

| Script | Purpose |
|---|---|
| `package_renderdoc_patched.ps1` | Combines patched PC binaries + Android APK + vendored aux files from an existing official install into a redistributable package. |
| `install_as_default.ps1` | Overlays a package onto `C:\Program Files\RenderDoc` so the patched build becomes the system default (with backup + rollback). |

## Prerequisites

1. A built PC RenderDoc under `<repo>\x64\Release` (or `x64\Development`).
2. A built Android arm64 APK under `<repo>\build-android-release\bin\` (or
   `build-android\bin\` for the Development variant).
3. An existing official RenderDoc install at `C:\Program Files\RenderDoc`
   whose auxiliary files (plugins, PySide2, libssl, renderdoc.chm, etc.)
   are vendored verbatim — these are unmodified by our patches.

## Workflow

```powershell
# 1. Build everything (from <repo>):
msbuild renderdoc.sln /p:Configuration=Release /p:Platform=x64 /m
# Android (needs ANDROID_NDK set and a VS Developer Command Prompt for include-bin):
cmake --build build-android-release --parallel 8

# 2. Package (default is Release; pass -BuildConfig Development for dev build):
powershell -ExecutionPolicy Bypass -File .\util\private-build\package_renderdoc_patched.ps1

# 3. (Optional) overlay onto C:\Program Files\RenderDoc:
powershell -ExecutionPolicy Bypass -File .\dist\RenderDocPatched-source-debug-release\install_as_default.ps1
```

Output goes to `<repo>\dist\RenderDocPatched-source-debug-release\` plus a
`.zip` next to it.  `<repo>\dist\` is in `.gitignore` so build artifacts
never enter the source tree.

## Receiver workflow

Hand the recipient the `.zip`:

1. Unzip anywhere.
2. Either run `qrenderdoc.exe` portably, or run the bundled
   `install_as_default.ps1` to overlay it onto `C:\Program Files\RenderDoc`
   (the script self-elevates and backs up the existing install first).
3. To roll back: run `install_as_default.ps1 -Restore`.

The package's bundled `README.md` (generated by `package_renderdoc_patched.ps1`)
covers the full end-user instructions including troubleshooting.
